## Projects

| Project | What it does | Built with |
| --- | --- | --- |
| [lora-stack-lab](https://github.com/P-Bao/lora-stack-lab) | Tests whether recent LoRA improvements (GraLoRA, GoRA, AltLoRA, BA-LoRA) still help when combined. Clean-room reimplementations on one pinned `peft` version. In progress. | Python, PEFT, Kaggle T4 ×2 |
| [TwoStage-MCQ-Generator](https://github.com/P-Bao/TwoStage-MCQ-Generator) | Generates multiple-choice questions from documents in two steps: one fine-tuned Llama-3.2-3B writes the question and answer, a second writes the wrong options. | Python, Llama 3.2, LoRA, Jupyter |
| [ptit-facebook-spam-ham](https://github.com/P-Bao/ptit-facebook-spam-ham) | Classifies Facebook comments from PTIT student groups as spam or not. A team of four compared TF-IDF with SVM against a fine-tuned viBERT on the same 7,474 test comments. | Python, scikit-learn, viBERT |
| [LDA-Visualization](https://github.com/P-Bao/LDA-Visualization) | LDA topic model for Vietnamese, written from scratch with Gibbs sampling. A step-by-step player shows how a paragraph becomes a summary. | Python, Flask, JavaScript |
| [AI-Mock-Interview](https://github.com/P-Bao/AI-Mock-Interview) | Mock job interviews held entirely by voice with an AI interviewer, for students about to enter the job market. | JavaScript |

Smaller things: Kubernetes deployment scripts in [k8s-deployment](https://github.com/P-Bao/k8s-deployment), a [photo-sharing](https://github.com/P-Bao/photo-sharing) app, and C++ data-structure and algorithm practice in [Olympic---DSA](https://github.com/P-Bao/Olympic---DSA) and [TRR_II_PTIT](https://github.com/P-Bao/TRR_II_PTIT).
